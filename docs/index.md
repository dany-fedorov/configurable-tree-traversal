# Documentation map

[Home and quickstart](../README.md) · [Agent workflow guide](agent-workflows.md) · [API reference](reference.md)

The [client API migration](migration-client-api.md) covers corrected observation, configuration, hydration and rewrite contracts. The [API naming migration](migration-api-clarity.md) covers renamed contracts and removed import routes; the [uniform API migration](migration-uniform-api.md) covers changed defaults and removed forms. Read only the path relevant to your task; internal plans and research are historical evidence, not the public API contract.

## Runnable examples

Examples are executable programs; the DAG and agent coordination examples include behavioral assertions. From a repository checkout, run `npm ci`, then `npm run tsfile -- examples/agent-api-foundations-example.ts`. Run all examples with `npm run verify-examples`.

| Example                                                                                                                                        | Demonstrates                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [Agent API foundations](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/agent-api-foundations-example.ts)       | Collection → prepared definition → independent sync/async sessions, local tickets, duplicate reports, and recovery without source replay |
| [Agent orchestration](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/agent-orchestration-example.ts)           | Typed prepare → run → guarded frontier → settle → run, final completion, duplicate settlement, and restart reconstruction                |
| [Reconciliation](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-reconciliation-example.ts)                 | Retained-runner and rebuild-per-tick equivalence                                                                                         |
| [Completion joins](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-completion-dependencies-example.ts)      | Waiting for a composite and its retained children                                                                                        |
| [Prerequisite lookup](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-prerequisite-resolution-example.ts)   | Async catalog lookup, transitive prerequisites, detached components                                                                      |
| [DAG inspection](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-inspection-example.ts)                     | Captured W/C navigation, seeded parent work, child completion blockers, and stable explanations                                          |
| [DAG fragments](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-fragments-example.ts)                       | Typed ports, two object-ID instances, a completion wire and independent sync/async sessions                                              |
| [DAG revisions](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-revision-example.ts)                        | Atomic data replacement, declaration diff, isolated tickets and host-selected completed-work seeds                                       |
| [Graph context](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/graph-walk-context-example.ts)                  | Mixed hydration, shared targets, parallel/back edges, isolated roots; five vertex and six edge callbacks                                 |
| [Typed code references](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/graph-walk-references-example.ts)       | Async hydrated endpoint narrowing, callbacks/iteration, common inspection and family-safe execution wrappers                             |
| [Bounded provenance](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/graph-walk-paths-example.ts)               | Simple paths/repeated walks, parallel route identity and explicit limited/exhausted outcomes                                             |
| [Event delivery selection](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/event-delivery-selection-example.ts) | Settlement observations, changed delivery selectors, independent callbacks and precise iterator kinds                                    |
| [DAG traversal](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/dag-workflow-example.ts)                        | Shared vertices and work versus structural completion                                                                                    |
| [Async tree adapter](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/async-adapter-example.ts)                  | Promise-returning discovery and visitors                                                                                                 |
| [Object rewrite](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/examples/rewrite-object-example.ts)                     | Transforming nested values                                                                                                               |

The npm package includes these guides and the reference. Examples, contributor instructions, and measurement artifacts are linked to the repository rather than bundled.

## Evidence and history

- [Changelog](../CHANGELOG.md): changes and release history.
- [Testing](testing.md): commands, coverage requirements, package/runtime checks.
- [Performance reports](https://github.com/dany-fedorov/configurable-tree-traversal/tree/main/docs/performance): measured artifacts and explicit limits; not universal speed guarantees.
- [Agent API roadmap](https://github.com/dany-fedorov/configurable-tree-traversal/blob/main/docs/superpowers/specs/2026-10-25-agent-api-roadmap.md): ten proposals; the current reference documents the implemented collection, preparation, coordination, fragment composition, validated revisions, dependency inspection, event and visitor APIs. General graph walking (9) is implemented; items 5 and 10 remain future work.
- [Research](https://github.com/dany-fedorov/configurable-tree-traversal/tree/main/docs/research) and [design plans](https://github.com/dany-fedorov/configurable-tree-traversal/tree/main/docs/superpowers): decision history. Some proposals are superseded or describe downstream work that CTT does not implement. Use current guides and source/tests to establish behavior.
