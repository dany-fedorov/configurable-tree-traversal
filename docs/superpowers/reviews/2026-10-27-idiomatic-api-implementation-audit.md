## Surface and documentation closure

The updated `scripts/api-clarity-census.cjs` requires an explicit evidence directory and retains recursive signature/member/static/constructor traversal, inherited/mapped relationships and private engine guards. It emits the complete supported binding/declaration inventory plus literal/callback/generic vocabulary. Canonical-name guards and retired declaration/member checks supplement runtime/type tests; no public deprecated declaration is allowed. Useful never constraints are classified as rejection, and physical module filenames/import strings are not public bindings.

The nine runtime entrypoints plus package metadata are unchanged. `scripts/package-consumers/supported-exports.ts`/`.mjs` preserve real denial of all 26 private routes (including .js variants), with independent physical-file-existence controls and exact observed Node/Bun denial codes, and the package verifier checks shared CJS/ESM constructors/sentinels/namespaces/declarations. The complete consumer fixture set compiles under strict node/node16 resolution, including .ts/.cts/.mts, without skipLibCheck. The typed-ID fixture rejects untagged source content directly, alongside canonical typed-ID and missing-ID controls; it no longer uses an empty Extract domain whose diagnostic locations differed between the supported compilers. The final matrix executes the same final build under actual Node 24.20.0, Node 22.12.0 and Bun 1.4.4 with TypeScript 4.9.5 and 4.7.4; actual exits, rather than an inferred engine claim, belong in the report.

[The new migration guide](../../migration-idiomatic-api.md) is linked by README, docs map, reference and AGENTS and listed in package.json files. Existing guide section anchors remain. Current examples use canonical names; current reference's obsolete positional-overload claim is corrected. Package verification checks links/anchors both in checkout and extracted tarball, asserts guide packaging and compiles/executes every marked standalone snippet; the example verifier discovers all top-level examples. Historical reviews/research/specs/plans are unchanged. No release-status caveats, publication/dependency/version changes, or host dispatch/storage features were added.

Optional F14 spelling disposition: public current object-domain declarations use InputTypes/OutputTypes where the type repair required clarity; physical filenames and remaining internal parameter names are implementation details. No purely stylistic generic rename/reorder is required, and no optional spelling is treated as a missing behavioral fix. Remaining limits are those in the guide: shallow caller data, local generations/tickets, observational snapshots, cooperative draining and host-owned durable acceptance.
