## Illustration: one possible opening hook (not counted)

> **Give CTT your agents' task graph and the results you have already accepted. Each `advance()` returns exactly the tasks whose dependencies are satisfied, as tickets only that session can redeem. CTT never runs a task and never stores anything, so after a crash you rebuild the same frontier from your own accepted facts.**

Evidence: tickets are issued from the deferred frontier and owned through a private WeakMap at src/traversals/dag-traversal/coordinateDag.ts:112-127; foreign tickets throw at coordinateDag.ts:89-92, asserted in tests/dag-coordination.test.ts:78-89 and examples/agent-api-foundations-example.ts:72. Rebuild equivalence is asserted at examples/dag-reconciliation-example.ts:73-77. The source has a single runtime import, uuid (src/core/CTTRef.ts:1), and no storage code. Caveats: "exactly" holds for prepared sessions because they call `prepare()` eagerly (makePreparedDag.ts:70); lazy runners can expose a partial frontier (docs/reference.md:745-746). Readiness is dependency eligibility, not host claims (docs/agent-workflows.md:64). The hook is only truthful on the npm page once finding 1 is resolved.
