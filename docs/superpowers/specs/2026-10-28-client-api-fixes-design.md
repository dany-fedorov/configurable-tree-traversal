## Requirements and chosen contracts

1. **F01 — truthful object rewrite domains.** Default current values, assembled values, assembly caches and rewrite input values to unknown. Requested replacements retain their declared payload types. Replace getOutputObjectFromRootValue with convertRootValue(value: unknown, context: {readonly complete: boolean}). Ordinary rewriteObject requires a converter before promising a specific Out; rewriteObjectAs remains the explicit unchecked final assertion. Preserve completion gating and successful output caching. No generic-only assertion may restore unsupported assembly precision.
2. **F02 — truthful discovery domains.** Default object property discovery exposes PropertyKey/unknown. Narrow key/value domains require both a root mapper and child mapper; provide ObjectTreeSource.fromProperties for that precise route. Apply the requirement through rewrite helpers. Default helper signatures preserve the actual root value and root-key type; no arbitrary generic casts at public defaults.
3. **F03 — observation without editing authority.** Public views, event records, callback arguments/contexts, source resolution contexts and graph records expose stable VertexHandle/VertexView facades. Handles support getRefId/getValue but no setValue; views expose query methods and detached readonly hints, no vertex setters. Runtime JavaScript facades restrict the same authority as the types. Opaque caller data/IDs retain identity and are not deep frozen. Keep explicit standalone mutable Vertex/MutableRef/store editing as advanced capabilities; do not leak mutable stores through ordinary runner callbacks. Commands continue to edit using stable handles internally.
4. **F04 — patch semantics.** For configure patches, missing or undefined fields retain prior settings, including nested in-order and phase fields. Malformed defined fields reject atomically before replacing active configuration. Null clears only explicitly nullable fields. Types support this under exactOptionalPropertyTypes.
5. **F05 — strict option boundaries.** Use allowlists at public builder/helper/options/patch boundaries. Reject unsupported own keys (including symbol keys) with TypeError before user callbacks or mutation. Inherited protocol methods on sources remain valid; task data remains opaque. Builders retain their supported execution-option placement, rejecting unsupported fields rather than silently accepting them. Helpers project their own combined options before calling lower-level constructors.
6. **F06 — walking hydration contract.** Sources declare hydration: resolver or inlineOrCached. Resolver mode requires resolveVertex and permits mixed inline and ID targets. InlineOrCached mode forbids a resolver and uses tagged {kind:'inline',vertexId,resolution} or {kind:'cached',vertexId} targets. Cache-first admission remains; cached targets reject if not already resolved in this runner. Preserve no-resolver self/backedges, omissions and async protocols. Materializers/adapters declare resolver mode. No untyped legacy source-shape fallback.
7. **F07 — preparation validation.** Convert only engine-originated discovery cycles into an invalid preparation issue {kind:'discoveryCycle',vertexIds:readonly ID[]}, retaining its ordered closed witness. Keep structuralCycle SCC issues distinct. Preserve exact callback-thrown values, including callback-thrown instances of engine error classes, and malformed-contract exceptions. Apply sync/async consistently.
8. **F08 — completion naming.** Rename workCompletion visitorReturn to afterWorkReadyChain. Empty/filtered chains complete automatically; externalSettlement and explicit deferral retain their semantics. Reject the old literal at runtime.
9. **F09 — uniform emission timing.** Use delivery-time emitEvents filtering across tree/DAG/walking, including buffered observations after resumption. Snapshot visitor admission independently. Never replay committed work or rerun callbacks to satisfy a changed selector. Narrow explicit delivery selections where sound in public iterator types. Do not add an eventSelection timing policy.
10. **F10 — array placement.** Add arrayIndexPolicy compactInTraversalOrder (default) or preserveNumericKeys. Preservation assigns valid integer array indices 0..2^32-2, retains holes, rejects invalid numeric indices; custom assembleArray owns reconstruction and supersedes this built-in policy. Named array properties remain supported.
11. **F11 — collisions.** Built-in assembly exposes propertyCollision error (default), firstWins or lastWins. Compare normalized JavaScript property keys, preserving symbol identity; apply to objects and array named properties, plus preserved numeric positions. Custom assemblers own their collision behavior. Never silently lose values under the default.
12. **F12 — opaque work tickets.** Expose type-only nominal class-shaped tickets with a private member/constructor. Spreads cannot satisfy settlement parameters. Keep runtime provenance/WeakMap validation and original ticket identity; no public constructor, persistence or claims semantics.
13. **F13 — unambiguous child positions.** ChildIndexSelection is {indices:readonly number[]} or {ranges:readonly {from:number;through:number}[]}, for both primary and fallback positions. Preserve negative indexing, inclusive endpoints, normalization and fallback rules. Reject old ambiguous shorthands.
14. **F14 — complete progress outputs.** Engine progress records always contain readonly unmetWorkPrerequisiteIds and unmetSubgraphPrerequisiteIds arrays, empty when appropriate. Do not derive W by subtracting C from a union. Update manual fixtures or provide a separately named fixture/input type only if a real consumer needs it.
15. **F15 — exclusive mutation operations.** Generic MutationRequest uses kind rewrite with value, delete or keep; object specialization uses kind rewrite with patch. Omission retains default assembly behavior, as does keep for the relevant existing NOOP/assembly semantics. Reject conflicting/malformed JavaScript operations. Remove old rewrite/delete optional-field shape.
16. **F16 — hook scope.** Rename resolveVertexHook/ObjectVertexHookResult to resolveChildHook/ObjectChildHookResult. Root mapping remains separate; reject the old hook option.
17. **F17 — graph view vocabulary.** Rename ResolvedGraph/getResolvedGraph/resolvedGraph to ResolvedGraphView/getResolvedGraphView/resolvedGraphView at public boundaries. OriginalGraphView, PreparedDag and DagMilestoneSnapshot remain distinct.
18. **F18 — walking selector names.** Export GraphWalkRecordSelectors, AsyncGraphWalkRecordSelectors and GraphWalkCatalogLink with readonly to/data. Materializer signatures consume them. Catalog relations remain distinct from lazy targets.
19. **F19 — diagnostic consistency.** Tree/DAG sorter operation is sortChildrenHints; visit labels are visit for every family. Keep distinct iterator operations and lifecycle/phase/count domains.
20. **F20 — root predicates.** Remove isTraversalRoot/isTraversalRootVertex from supported public event/context/runner contracts. Retain isTreeRoot/isGraphRoot and walking entry occurrences. Remove stale subtree-start documentation; do not invent a startAt feature.
